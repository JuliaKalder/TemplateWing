Welcome to TemplateWing

Save the emails you write again and again, then drop them into a new message with one click. Attachments and recipients come along.

Read the quick guide

Getting started

  1. 1

    Create a template

    Open the template manager and save a text you send often. Subject, body, recipients and file attachments are all part of the template.

  2. 2

    Open a compose window

    Click the TemplateWing button in the compose toolbar, or right-click in the message body and choose “Insert Template”.

  3. 3

    Insert and send

    Pick a template and everything is filled in at once. For the first nine templates you can also press Ctrl+Shift+1 to Ctrl+Shift+9.

What you can do

Templates with attachments

Files are stored with the template and get attached automatically every time you insert it.

Variables

Placeholders like {DATE}, {RECIPIENT_FIRSTNAME} or {SENDER_NAME} are replaced when you insert the template.

Conditional blocks

With {IF recipient.domain=="acme.com"} … {ELSE} … {ENDIF} the same template can show different text depending on who you are writing to.

Ask on insert

{PROMPT:Order number} and {CHOICE:Tone:formal|casual} open a small dialog before insertion, so you can fill in whatever changes each time.

Default template per account

Pick a template that appears automatically in every new message for a given identity. Replies and forwards are left alone.

Your data stays local

Everything is kept in Thunderbird’s local storage. No account, no telemetry, no network requests.
