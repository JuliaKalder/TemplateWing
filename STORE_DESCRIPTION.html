TemplateWing lets you save and reuse email templates, including file attachments, directly from the Thunderbird compose window.

Features

  • Rich text editor — Format templates with bold, italic, underline, lists, headings, and quotes
  • File attachments — Attach files to templates; they are stored and added automatically on insert
  • Subject, recipients & insertion mode — Set a default subject, To/Cc/Bcc addresses, and choose whether the template appends, prepends, replaces, or inserts at the cursor
  • Categories — Organise templates into categories and filter by them in the popup and options page
  • Variables — Use date/time tokens ({DATE}, {TIME}, {DATETIME}, {YEAR}, {WEEKDAY}), sender identity ({SENDER_NAME}, {SENDER_EMAIL}, {ACCOUNT_NAME}, {ACCOUNT_EMAIL}), recipient details ({RECIPIENT_NAME}, {RECIPIENT_FIRSTNAME}, {RECIPIENT_EMAIL}), and reply context ({REPLY_QUOTE}, {LAST_MESSAGE_SUBJECT}) — resolved automatically on insert
  • Conditional blocks — {IF recipient.domain=="acme.com"}…{ELSE}…{ENDIF} lets one template adapt to who you're writing to
  • Ask-on-insert prompts — {PROMPT:Label:default} for free text and {CHOICE:Tone:formal|casual} for fixed options open a small dialog before insertion
  • Nested templates — Reuse common building blocks with {{template:Signature}}
  • Favorites & live search — Pin your most-used templates to the top and type to filter the popup instantly
  • Per-identity default template — Pick a template that auto-inserts when you open a new compose window for that account (skipped on reply/forward)
  • Keyboard shortcuts — Insert your first 9 templates with Ctrl+Shift+1 – Ctrl+Shift+9 from the compose window
  • Usage dashboard — Sortable table, top-10 chart, "unused for X days" filter, and CSV export of insertion stats
  • Template linter — Warns you in the options list about unknown variables, broken nested includes, oversized attachments, or invalid recipient addresses before you ever hit send
  • Import / Export with per-row preview — Back up templates as JSON; on import, see every template with a NEW/DUPLICATE badge and decide per row whether to skip, add as a copy, replace, or rename
  • Multi-select & bulk actions — Tick several templates in the options list and change their category, export that selection, or delete them all at once
  • Welcome tab — A short tour opens once after installation, so the first template is quick to create
  • Save from email — Right-click any message in the message list → "Save as Template" to create a template pre-filled with subject and body
  • Dark mode — Follows the system colour scheme automatically
  • Localized — Complete UI in English, German, French, Spanish, Italian, Portuguese, and Dutch

Privacy

All data is stored locally on your device using Thunderbird's built-in storage API. No network requests, no telemetry, no analytics. Nothing is collected, transmitted, or shared. The welcome page shown after installation links to the project page and a donation page; those open in your normal browser only if you click them.
